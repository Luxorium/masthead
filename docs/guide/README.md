# Masthead guide

Masthead is an app on your own computer that runs a team of AI helpers for you, in your web browser.
You talk to one main assistant. When the work calls for it, it brings in helpers, using the Claude
Code (or Codex) already installed and signed in on your computer.

**Good to know**

- Masthead runs on your computer only. It has no account or login of its own and never sees your
  Claude or Codex password.
- Every helper uses your own Claude (or Codex) plan, exactly as the program would on its own. A team
  uses it faster than a single chat.
- Masthead has been checked on Linux and Windows 11. On macOS it is tested automatically but has not
  yet been tried on a real Mac.
- Masthead is not affiliated with Anthropic or OpenAI. See [the notice](accounts-and-terms.md).
