# Build configuration

Files: `package.json`, `package-lock.json`, `tsconfig.server.json`, `tsconfig.web.json`, `vite.config.ts`, `svelte.config.js`, `.gitignore`. How to use them is on [Building, testing and installing](Building-Testing-Installing.md); this page explains what each file says.

## `package.json`

- `name` `masthead`, `version` `0.1.3`, `private`, `"type": "module"` (files are ES modules: `import`/`export`).
- `bin`: `masthead` → `dist/server/main.js`.
- `engines`: Node 22 or newer.
- Runtime dependencies:

| Package | Used for |
|---|---|
| `@anthropic-ai/claude-agent-sdk` | Starting and driving Claude Code (`query`, `tool`, `createSdkMcpServer`). |
| `ws` | The WebSocket server (`server/http.ts`). |
| `zod` | Input schemas for the team tools (`server/tools.ts`). |
| `marked`, `dompurify`, `highlight.js` | The page only: Markdown rendering, HTML cleaning and code highlighting (`web/src/lib/markdown.ts`). |

- Development dependencies: TypeScript, Svelte 5, `svelte-check`, Vite and its Svelte plugin, `tsx` (runs TypeScript directly, for tests), `playwright-core` (drives a browser for `test/ui.e2e.mjs`), and type packages for Node and `ws`. The installed copy omits all of these (`npm ci --omit=dev`).
- Scripts: see [Building, testing and installing](Building-Testing-Installing.md#npm-scripts).

`package-lock.json` pins exact versions; it is generated by npm and not described here.

## `tsconfig.server.json`

Compiles `server/**/*.ts` and `shared/**/*.ts` to `dist/` (keeping the folder structure, `rootDir: "."`). Targets ES2023 with Node's module system (`NodeNext`), which is why imports inside the server end in `.js` (for example `import { App } from './app.js'`) even though the files are `.ts`. `strict` and `noUncheckedIndexedAccess` are on: indexing an array or map gives a possibly-undefined value, which explains the `!` and `??` seen around array and map access in the code.

## `tsconfig.web.json`

Type-checks `web/src/**/*.ts`, `web/src/**/*.svelte` and `shared/**/*.ts` for the browser (DOM libraries, bundler-style module resolution). `noEmit`: Vite does the actual building; this file is only for `svelte-check`.

## `vite.config.ts`

- `root: 'web'`: the page's source lives in `web/` (Vite uses `web/index.html` as the entry).
- Svelte plugin, pointed at `../svelte.config.js` (the path is relative to the `web/` root).
- Build output `../dist/web` (that is, `dist/web`), emptied on each build, targeting ES2022.
- Development server on port 7718, proxying `/ws` (as WebSocket) and `/api` to `127.0.0.1:7717`.

## `svelte.config.js`

Uses Vite's preprocessor so `.svelte` files can contain TypeScript.

## `.gitignore`

Ignores `node_modules/`, `dist/` and `*.log`.
